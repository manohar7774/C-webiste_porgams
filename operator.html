Question 2 :Write a program to show that example of post-increment ?

Program:

#include <stdio.h>

void main() {
    int a = 7;

    printf("Before increment = %d\n", a);
    printf("Post-increment = %d\n", a++);
    printf("After increment = %d\n", a);

}

Input:

Enter a number: 7

Output:

6
